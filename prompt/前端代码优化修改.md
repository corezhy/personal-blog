## 1.登录没有发送请求

问题：就是你的登录为什么点击后没有发送请求，我知道你写了模拟登录，但是后面肯定是要和后端交互的

```
怎么接真实后端

  好消息:这套代码就是按"删掉 Mock 就能接后端"设计的,切换点很少:

  1. 关掉 Mock — .env.development 改一行:

  VITE_ENABLE_MOCK=false

  2. Vite 代理已配好 — vite.config.ts:23:

  '/api': { target: 'http://localhost:8080', changeOrigin: true }

  所以请求会走:浏览器 → Vite dev server(5173)→ 代理 → http://localhost:8080/api/auth/login。注意代理没有 rewrite,后端需要带 /api 前缀;如果后端接口不带
  /api,把注释掉的 rewrite 那行打开即可。
```

## 2.前端写死的mock文章

问题：你现在给我的文章是前端写死的mock数据吗，我改了 VITE_ENABLE_MOCK=false 就不会显示了对吧，因为数据是要后端返回的，所以我必须弄清楚 

```
是的,现在的文章就是前端写死的 Mock 数据

  数据源头在 src/services/mock/data.ts,里面硬编码了 14 篇文章(标题、分类、标签、点赞数、Markdown 正文全在代码里)。
  
  它的运作方式:
     
  HomePage
    → useArticleList 钩子
    → getArticles()          (services/article.ts)
    → request.get('/articles')  → axios
    → axios-mock-adapter 拦截       ← VITE_ENABLE_MOCK=true 时在这里被拦住
    → 返回 data.ts 里写死的 14 篇

  所以 VITE_ENABLE_MOCK=false 之后:

  request.get('/articles')
    → axios 真实发请求
    → Vite 代理 → http://localhost:8080/api/articles
    → 没有后端 → 请求失败(代理连不上 8080)
    → 首页文章列表空白(显示骨架屏/空状态)

  完全正确,文章不会显示了。因为数据必须由后端返回。
```
