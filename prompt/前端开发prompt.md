## 1.项目初始思路实现

```
你是一名资深前端架构师，现在有以下需求，编写个人博客前端界面。
遵守条约：
1. 技术选型:
核心框架: vue3		开发语言: TypeScript5.x
构建工具: vite8		路由管理: vue Router 4
状态管理: Pinia		http客户端: Axios
UI组件库: Element-plus  css方案: Tailwind CSS 4
代码规范: ESlint9 + Prrttier3

2. 可扩展性架构设计，后续项目会持续升级，必须规范编码，绝对不能“面条式”
pages/ (路由层) 仅负责组装布局，不写业务逻辑
components/ (组件层) 拆分出 common/ (通用UI) 和 business/ (业务组件)
hooks/ (逻辑层) 所有网络请求、状态管理封装成自定义 Hook
stores/ (状态层) 使用 Zustand 或 Pinia，按功能切片(如 useAuthStore、useThemeStore)
services/ (API层) 统一封装 axios/fetch，定义好请求拦截器。
types/ (契约层) 重中之重！先定义好所有数据结构（文章、分类、用户）

3. 初始页面设计
主题风格: 支持明暗主题切换，切换按钮在顶部导航栏，点击后即可切换不同主题

登录页面: 包含用户名和密码输入框，严禁出现“注册”、"忘记密码"、“发送验证码”等多余表单元素
登录成功后，如果 role === 'admin'，跳转至 /admin/dashboard (后台布局)
如果 role === 'user'，跳转至 / (前台布局)，可以支持点赞等，但是禁止修改/发布/删除文章
如果用户没有Token，直接访问首页 / (游客登录) 依然能正常加载文章列表和详情页 (不支持点赞等)
登录失败统一提示“用户名或密码错误”
后端返回JSON如下:
{
  "code": 200,
  "data": {
    "token": "xxx.xxx.xxx",
    "userInfo": {
      "id": 1,
      "name": "管理员",
      "role": "admin"   // 或者是 "user"
    }
  }
  "msg": ""
}

文章列表页: 支持分页(无限滚动 + 滚动到一定位置会出现一个箭头，点击后回到顶部)、按时间倒序排列

文章详情页: 支持Markdown渲染、代码高亮、目录锚点 (TOC) 自动生成

分类与标签系统: 侧边栏显示分类云/标签云，点击筛选对应文章

归档页: 按年月聚合文章的时间线 (Archives)

关于/友链页: 静态配置页面

用户访问页面不存在需要有404页面

同一个页面不同布局，假如管理员和普通用户看同一个页面，但是管理员多一个“新增/编辑/删除”按钮

4. 后端统一返回结果包含code 、 data 、msg

5. 后端端口为localhost:8080，前端为5173，请处理好跨域问题
```
